# Contributing

Contributions are welcome for noncommercial hobby, research, and learning use.

By submitting a pull request or patch, you agree that your contribution may be
included in this project under the same license as the rest of the repository:

```text
PolyForm Noncommercial License 1.0.0
```

Good contribution areas:

- new model presets
- better prompt/tag matching heuristics
- safer Smart Formatting behavior
- documentation and workflow examples
- ComfyUI node compatibility fixes
- database import/sync improvements

Please do not submit private `.env` files, generated SQLite databases, model
files, or large local caches.
